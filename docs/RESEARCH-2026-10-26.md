# Demo research — 2026-10-26

Three parallel research passes: x402-on-Solana landscape, live IPFS/libp2p demo patterns, Solana-native features. [V] = verified (source read, endpoint queried, or code checked); [U] = unverified, check before relying on it.

## Positioning

- **Prior art: Betar** (github.com/asabya/betar). [V] It is a Go P2P agent marketplace doing x402 over libp2p streams, paying with USDC on Base Sepolia (EVM). Created 2026-02-16, 4 stars. Do **not** claim "first x402 over libp2p".
  - What we can claim: first on **Solana**, first for **IPFS pin/fetch between peers**, first **x402 v2 transport spec** for libp2p. The upstream `specs/transports-v2/` has only http/mcp/a2a.
  - Check Betar's protocol ID (`/x402/libp2p/1.0.0`) and coordinate rather than collide.
- **Every x402 storage product is an HTTP gateway**: Pinata pay-to-pin, x402.storage, Taiko Tack, toju/afara. None pays *a peer* to pin for another peer.
- **Solana x402 hackathon (Nov 2025) and Colosseum Cypherpunk winners** were MCPay, Corbits, PlaiPin and others. No storage/IPFS winner. The entries that got attention were physical hardware (PlaiPin) and dashboards (Corbits).

## IPFS / libp2p: what holds up on stage

- **Browser tabs can be dialed only via circuit-relay v2, then WebRTC upgrade.** [V] We need our own relay (VPS, WSS via AutoTLS).
  - js WebRTC ships STUN only, no TURN [V]. Bring coturn, or accept staying on the relayed path.
- **`@helia/car` import does not hash-verify blocks.** [V] Our pin and fetch paths must check every block's digest themselves. That check is also the on-screen "verified" tick and the tamper demo.
- **A browser node cannot announce to the public network.** [V] A NATed laptop shouldn't either.
  - Kubo ≥0.39 announces the root immediately on `dag import` [V]. Prove it live with `delegated-ipfs.dev/routing/v1/providers/<cid>` and `check.ipfs.network`.
- **Best past model: libp2p Universal Connectivity** (go/rust/js/browser on one shared view, live transport per connection).
- **Gotchas:**
  - v3 streams are EventTargets; use `@libp2p/utils` stream helpers.
  - Helia uses `@libp2p/noise` / `@libp2p/yamux`; we still use `@chainsafe/*`. Switch to avoid duplicate copies.
  - `@libp2p/webrtc` 7 vs Helia's `^6`. Pin versions.

## Solana depth, ranked for a credible demo

1. PeerId = wallet, with the payTo check (built). Lead with it.
2. Content CID in the x402 memo, plus an explorer link per payment.
3. A live Kit websocket ticker showing processed → confirmed → finalized, with measured ms.
4. A self-hosted facilitator (Kora or `@x402/svm`), so agents hold USDC and no SOL.
5. A Surfpool / local-validator fallback for the venue.

Stretch: `upto` pin via payment channels; Solana Pay QR so an audience member pays from a phone (friction: phones are on mainnet); SAS attestations; Bubblegum v2 pin certificates. Last: an Anchor provider registry (duplicates the DHT, L effort).
